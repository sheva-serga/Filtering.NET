# FN0006 — Unknown operator on profile

**Severity:** Error

## What triggers it

A `[Map(Only = new[] { "fuzzy" })]` (or `Except = ...`) names an operator that doesn't exist on the resolved profile — either misspelled or simply not declared.

## Why it matters

Validation arms and predicate dispatch arms key off the operator name. Letting unknown names through would silently fail at apply-time instead of at compile-time.

## Fix

Spell the operator the way the profile declares it (operator names are case-sensitive). For built-in profiles see the `Profiles/*.cs` runtime files; for custom profiles inspect each `[FilterOperator("…")]`.
