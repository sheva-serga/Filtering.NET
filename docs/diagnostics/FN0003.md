# FN0003 — Property has both `[Map]` and `[PropertyMap]`

**Severity:** Error

## What triggers it

A single property is targeted by both a `[Map]` partial method (the standard configuration syntax) and a `[PropertyMap]` override declaration that supplies a custom accessor.

## Why it matters

`[Map]` and `[PropertyMap]` are two paths into the same dispatch table. Allowing both would force a precedence rule that's easy to get wrong.

## Fix

Pick one. If you need a custom accessor expression, use `[PropertyMap]` exclusively for that property and drop the `[Map]`.
