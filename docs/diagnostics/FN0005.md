# FN0005 — Incompatible profile for property

**Severity:** Error

## What triggers it

A `[Map(Profile = typeof(SomeProfile))]` references a profile whose declared value type doesn't unify with the property's CLR type — for example, applying `StringFilter` to an `int` column.

## Why it matters

Profiles encode the legal `(value-type, operator)` pairs. Mismatching them produces predicates that don't compile.

## Fix

Drop the explicit `Profile =` to let the generator infer it from the property type, or pick a profile that actually targets the property's CLR shape. Custom profiles can opt into multiple shapes via `[FilterProfile(BasedOn = typeof(...))]` chains.
