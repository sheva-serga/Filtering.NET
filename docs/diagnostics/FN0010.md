# FN0010 — Duplicate value interceptor

**Severity:** Error

## What triggers it

A property has more than one `[InterceptValue]`-marked method targeting it.

## Why it matters

Interceptors run inline in the generated leaf for that property; the generator picks one slot. Allowing duplicates forces an undocumented ordering rule.

## Fix

Compose your interception logic into a single method, or split the surface into two distinct properties so each has its own interceptor.
