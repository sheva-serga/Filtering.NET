# FN0013 — `[FilterProfile.BasedOn]` references a non-profile type

**Severity:** Error

## What triggers it

`[FilterProfile(BasedOn = typeof(SomeType))]` names a type that itself isn't decorated with `[FilterProfile]`.

## Why it matters

`BasedOn` walks an inheritance chain to merge operator declarations. If a link in the chain isn't a profile, the merge has nothing to consume.

## Fix

Either add `[FilterProfile]` to the parent type or drop the `BasedOn =` argument.
