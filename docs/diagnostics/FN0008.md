# FN0008 — `[Map]` method must be partial

**Severity:** Error

## What triggers it

A `[Map]`-decorated method on a `[GenerateFilter<T>]` partial class is declared without the `partial` keyword.

## Why it matters

The configuration pattern relies on a `partial` declaration whose body the generator supplies as a no-op marker. Non-partial methods can't be paired with a generator-emitted implementation half.

## Fix

Add `partial`:

```csharp
[Map(nameof(User.Name))]
private static partial void MapName();   //  partial keyword required
```
