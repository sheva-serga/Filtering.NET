# FN0011 — `[FilterOperator]` member must be public static

**Severity:** Error

## What triggers it

A method or property carrying `[FilterOperator]` is not declared as `public static`.

## Why it matters

The generator references operator members by their fully-qualified static name from the emitted dispatch arms. Instance / private members would force per-call instantiation and break the generated code shape.

## Fix

Mark the member `public static`:

```csharp
[FilterOperator("eq")]
public static Expression<Func<string, string, bool>> Eq =>
    (column, value) => column == value;
```
