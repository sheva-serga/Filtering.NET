# FN0007 — Invalid value converter type

**Severity:** Error

## What triggers it

`[ConvertWith(typeof(MyConverter))]` references a type that does not inherit from `Microsoft.EntityFrameworkCore.Storage.ValueConversion.ValueConverter<TModel, TProvider>`.

## Why it matters

The generator pulls the `TModel` / `TProvider` type arguments off the converter base class to widen the leaf value extraction shape. A converter that doesn't extend `ValueConverter<,>` exposes no such metadata and cannot be wired into the emitted code.

## Fix

Inherit from `ValueConverter<TModel, TProvider>` (or one of its derived helpers). EF Core ships with many — see `Microsoft.EntityFrameworkCore.Storage.ValueConversion`.
