# FN1004 — Operator is declared but unused

**Severity:** Warning

## What triggers it

An `[FilterOperator("…")]` member sits on a profile that *is* referenced, but every consumer of the profile excludes the operator via an `Only =` whitelist (or excludes via `Except =`).

## Why it matters

Operators that no one can name are dead code. Either widen at least one consumer's whitelist or delete the operator.

## Fix

Drop the unused operator from the profile, or remove the offending `Only =` / `Except =` clause on at least one mapping so the operator becomes reachable.

A `[Map]` without an `Only =` / `Except =` retains every profile operator, so the warning only fires when *every* consumer has explicitly narrowed the operator out.
