# FN0001 — Duplicate filter mapping

**Severity:** Error

## What triggers it

Two or more `[Map]` partial methods on the same `[GenerateFilter<T>]` partial class point at the same property on the entity (case-sensitive match on `PropertyName`).

```csharp
[GenerateFilter<User>]
public partial class UserFilter
{
    [Map(nameof(User.Name))]                  private static partial void MapNameOnce();
    [Map(nameof(User.Name), Sortable = true)] private static partial void MapNameAgain(); // FN0001
}
```

## Why it matters

Each property gets exactly one validation arm and one predicate-builder arm in the generated code. Two `[Map]`s for the same property would produce two competing dispatch arms; the generator refuses to pick a winner.

## Fix

Pick one mapping declaration. If you need to vary configuration by call site (alias, `Only=`, etc.), introduce two distinct property names — for example, expose the underlying column under two different aliases.
