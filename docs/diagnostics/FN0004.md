# FN0004 — Property not found on entity

**Severity:** Error

## What triggers it

The `propertyName` argument (or dotted nav-path) of a `[Map]` doesn't resolve to a property on the entity type passed to `[GenerateFilter<T>]`.

## Why it matters

The generator can't emit a property accessor expression against a property that doesn't exist; it would produce code that doesn't compile.

## Fix

Use `nameof(Entity.Property)` to keep the binding refactor-safe. Check for typos. For navigations, ensure each segment of the dotted path exists.
