# FN0012 — Alias collides with existing property or alias

**Severity:** Error

## What triggers it

Two properties on the same filter class resolve to the same alias (case-insensitive). The collision can be alias-vs-alias, alias-vs-property-name, or two `[Map]`s with the same `Alias =`.

## Why it matters

The validation dispatcher uses `OrdinalIgnoreCase` lookups on field names; a duplicate would produce ambiguous routing.

## Fix

Pick distinct aliases, or scope the alias under a navigation prefix to disambiguate (`departmentName` vs `userName`).
