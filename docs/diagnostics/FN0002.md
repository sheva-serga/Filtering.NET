# FN0002 — Duplicate sortable mapping

**Severity:** Error

## What triggers it

The same property is marked `Sortable = true` on more than one `[Map]` declaration on the same filter class.

## Why it matters

Sort dispatch goes through a single `switch` on field-name in `ApplySorting`; duplicates would produce overlapping case labels.

## Fix

Keep `Sortable = true` on exactly one of the duplicate mappings, or eliminate the duplicate (see also `FN0001`).
