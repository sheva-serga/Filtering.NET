# FN1005 — Property allows zero operators

**Severity:** Warning

## What triggers it

A `[Map]`'s combination of `Only = …` / `Except = …` resolves to an empty operator set after intersecting with the profile.

## Why it matters

Filter leaves on this property will *always* fail validation with `OperatorNotAllowed`. The mapping is dead surface — usually a typo in the `Only =` / `Except =` list rather than an intentional lockdown.

## Fix

Re-check the `Only =` / `Except =` arrays. If you genuinely want the property to be unfilterable (sort-only), drop the `[Map]` entirely; sortability lives independently of filterability via a different attribute path.
