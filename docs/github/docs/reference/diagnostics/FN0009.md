# FN0009 — No inferable profile for property type

**Severity:** Error

## What triggers it

A `[Map]` is applied to a property whose CLR type has no built-in primitive profile (e.g., `Vector3`, `BigInteger`, a domain record), and no explicit `Profile = typeof(...)` was supplied.

## Why it matters

Without a profile the generator has nothing to dispatch on — there's no canonical operator set for arbitrary CLR types.

## Fix

Either supply `Profile = typeof(SomeCustomProfile)` on the `[Map]`, or define a custom `[FilterProfile]` and reference it. For one-off shapes consider `[PropertyMap]` which lets you write the accessor and operators inline.
