# FN1003 — Filter profile is declared but unused

**Severity:** Warning

## What triggers it

A `[FilterProfile]` class exists in the compilation but no `[Map(Profile = typeof(X))]` references it.

## Why it matters

Unused profiles are dead code. They also slow the generator's per-incremental run since they still get extracted and validated.

## Fix

Either reference the profile from at least one `[Map]`, or delete the profile.
